# Python Classes Practice

Simple Python programs on classes and objects.

- **rectangle**: Rectangle class with an area method
- **student**: Student class with a display_details method
- **product**: Product class with a calculate_total method
- **bank_account**: BankAccount class with deposit, withdraw, check_balance and customer_details methods
- **library_book**: Book class with calculate_stock_value and check_stock methods

## How to run

Open any `.py` file in Python IDLE and press **F5**.
